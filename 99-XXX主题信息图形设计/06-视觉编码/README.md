# 06｜视觉编码（重点：设计表达）

将数据字段与叙事信息单元转换为可识别、可读、可比较的视觉符号体系。本阶段不仅选图表，还需设计色彩、文字、图像、形态、空间与整体风格。

## 子目录
- [01-统计图形选择](01-统计图形选择/)：比较、构成、趋势、分布、关系、地理、层级、流动。
- [02-点线面体与图形符号](02-点线面体与图形符号/)：点、线、面、体、比例、位置、符号、引导线、箭头及图标语义。
- [03-色彩字体与版式](03-色彩字体与版式/)：色相/明度/对比、字体、字号、行距、字距、网格、留白和对齐。
- [04-照片插画与ISOTYPE图符](04-照片插画与ISOTYPE图符/)：摄影、插画、剪影、图形化、ISOTYPE重复图符，控制版权、风格及数量映射。
- [05-视觉编码规范与样张](05-视觉编码规范与样张/)：编码矩阵、图例规则、色彩方案、关键版式样张与版本。

## 设计操作顺序
1. 明确叙事信息单元的“类别/顺序/数量/空间/层级”变量。
2. 决定主通道：位置、长度、面积、角度、密度、线宽、颜色或重复符号。
3. 选择平面风格、照片风格、手绘/混合风格等，说明与受众/媒介的关系。
4. 规定字体、字重、字号级别、行距、字距、网格与留白，以支持阅读主次。
5. 需要 ISOTYPE 时明确 `1个图符 = ?单位`、重复规则和余数处理；没有数据依据时不将图符数量装饰化解释为统计量。
6. 复查图例、单位、极值比例、版面阅读路径、颜色区别和版权。

**重要**：平面/摄影等是视觉风格；文字型/照片型/词云是表现形式；条形图/矩阵是统计图形；不得用其中一个标签代替其他维度的判定。
