## 核心规范

1. **逐阶段承接**：从内容问题出发，先整理证据，再设计叙事与视觉表达；阶段可迭代但每次修订保留来源。
2. **数据字段原子化**：每一列只表示一个变量/属性，每个单元格只记录一个原子值。不是“一列只能有一行数据”；一列可以有很多行，每行一个值。不得把“名称+数值+单位”拼入同一个单元格。
3. **分类多维度**：底层逻辑（编年/层级/编目/字母表/地理）与成品类型（文字型、时间轴型、照片型、词云图、混合型等）及风格（平面、照片、手绘等）分开判定，允许多个辅助标签。
4. **字段组合生成信息单元**：例如 `名称 + 纬度 + 经度` 生成地图地点，`地区名称 + 年份 + GDP值 + 单位` 生成某地区某年 GDP 对比。组合字段要保留关联键、数据口径和出处。
5. **视觉编码必须可溯源**：点、线、面、体、大小、色彩、字体、行距、字距、照片、统计图形和ISOTYPE图符，都应说明为何这样设计以及是否编码真实数据。
6. **无资料不编造**：模板文件不是完成的研究成果。真实案例、数据集、图片、数值、设计成稿必须在获得素材后另行录入。
7. **原有知识库是参考，不改变**：[01 数据逻辑](../01-信息图形数据逻辑/README.md)、[02 类型案例](../02-信息图形类型案例/案例库/README.md)、[03 ISOTYPE](../03-ISOTYPE-基础图形设计/README.md)、[04 统计图形分析](../04-统计图形分析/)（目前为空）。
