# 01｜前期调研

## 目的
明确选题动机、传播目标、读者需求、知识范围与调研可行性，不在没有可靠材料时预设结论。

## 子目录
- [01-选题背景与研究问题](01-选题背景与研究问题/)：背景、范围、主要研究问题、关键词、研究假设。
- [02-目标受众与传播场景](02-目标受众与传播场景/)：读者特点、信息任务、展示场景、媒介及限制。
- [03-参考案例与设计调研](03-参考案例与设计调研/)：现有可视化/信息图形案例的来源、优缺点和设计机会。

## 推荐交付
1. 选题的一句话说明和3—5个可回答的问题。
2. 受众—读者任务—传播场景对应表。
3. 参考案例对照表：来源、表达形式、数据逻辑、有效之处、可改进之处。

**进入下一阶段的条件**：明确“想回答什么问题”，而不仅仅确定一个宽泛题目。
