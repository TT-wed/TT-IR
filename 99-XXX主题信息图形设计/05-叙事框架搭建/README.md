# 05｜叙事框架搭建

## 核心思想
从04的原子字段中选择若干列，形成一个有明确解释意义的**信息单元**，再将多个信息单元组织为叙事主题。叙事来自数据关系而不是先画一张好看的图。

## 字段组合示例（结构例子，不是实际数据）
- `地点名称 + 纬度 + 经度` → 地图地点信息；若有属性再编码点的颜色、大小。
- `地区ID/名称 + 年份 + GDP数值 + 货币单位` → 某年地区 GDP 比较/地图；应明确GDP口径、价格基期和来源。
- `时间 + 事件描述 + 事件类别` → 编年型时间轴信息单元。
- `父节点ID + 子节点ID + 数值` → 层级结构及规模。
- `词项 + 出现次数` → 词云权重信息单元，需说明分词和计数规则。

## 子目录
- [01-字段组合与信息单元](01-字段组合与信息单元/)：字段组合矩阵和数据连接条件。
- [02-叙事主题与结论](02-叙事主题与结论/)：读者问题、关键结论、需证实的假设。
- [03-信息架构与阅读路径](03-信息架构与阅读路径/)：总览→比较→细节、标题层级与阅读顺序。
- [04-叙事与数据溯源](04-叙事与数据溯源/)：每个结论可回到哪些原子字段和资料来源。

## 输出要求
至少说明**数据连接键、运算/聚合、视觉任务、结论的证据**；来源无法支持的观点不得作为既成事实。
