# 02｜主题内容分析（含大模型讨论）

## 目的
从调研问题出发，讨论内容内部的时间、等级、类别、索引或空间结构，并区分底层逻辑、成品信息图型及美术风格。

## 子目录
- [01-主题知识与内容拆解](01-主题知识与内容拆解/)：内容树、事实/概念/关系/争议。
- [02-数据逻辑与信息图类型判定](02-数据逻辑与信息图类型判定/)：主逻辑、辅逻辑、表现类型、统计图形可行性。
- [03-视觉风格与设计标签](03-视觉风格与设计标签/)：平面风格、照片风格、插画风格及标签组合。
- [04-大模型沟通记录](04-大模型沟通记录/)：保留问题、候选、证据、不确定性、最终决策和修订原因。

## 五种底层逻辑的判定问题
- **编年型**：如果去掉时间先后或时间间隔，核心事实是否就失去意义？
- **层级型**：对象之间是否有父子、包含或归属关系？
- **编目型**：是否主要基于分类、属性与条目进行组织？
- **字母表型**：是否主要依据字母、拼音或约定索引排序以支持查找？
- **地理图形**：是否必须借助地理位置、空间关系、区域或流向来理解？

## 分别讨论三个设计维度
1. **成品表现类型**：文字型/列表型、时间轴型、照片型、混合型、示意图等；词云需真实文本权重支持。
2. **视觉风格**：平面、摄影、手绘、拼贴、抽象、极简等，风格本身不决定数据逻辑。
3. **统计图形**：条形、折线、散点、矩阵、地图符号等，需按数据结构与读者任务选用。

## 结果格式
建议输出“主数据逻辑 + 辅数据逻辑 + 主成品类型 + 辅助类型 + 风格 + 图表备选 + 判断依据/反证”，不能仅凭视觉偏好直接定性。
