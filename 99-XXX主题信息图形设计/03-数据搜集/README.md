# 03｜数据搜集

## 资料分区
- [01-公共数据集](01-公共数据集/)：政府开放数据、统计部门、权威平台等，保留原始文件、下载链接、数据口径与时间。
- [02-文本文献](02-文本文献/)：论文、书籍、政策文件、文章、访谈及文本语料，保留书目信息与引用页码。
- [03-自建数据集](03-自建数据集/)：调查、观察、编码、拍摄、实验、采访产生的数据，明确采样方法与知情同意。
- [04-数据来源与授权台账](04-数据来源与授权台账/)：数据来源、获取日期、许可、可靠性、使用限制和待核查问题。

## 数据采集原则
1. 用唯一来源ID串联原始资料、基础数据表、可视图形和设计结论。
2. 原始数据不覆盖，只在04阶段生成规范化副本。
3. 文件、网址、版本、时间范围、计量单位、版权及使用许可均需标明。
4. 遇到缺失、冲突、估计数据，明确记录，不自行捏造数值。
