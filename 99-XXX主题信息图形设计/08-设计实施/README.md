# 08｜设计实施

## 目的
依据前述数据与叙事结构完成方案制作、设计稿、核验与最终交付；不凭视觉需要修改原始统计事实。

## 子目录
- [01-方案草图](01-方案草图/)：构图草图、风格探索、手绘与概念草图。
- [02-版式结构与组件](02-版式结构与组件/)：网格系统、标题模块、统计图形组件、图例与标注。
- [03-设计源文件与素材](03-设计源文件与素材/)：源文件、可合法使用的照片/插画及字体使用记录。
- [04-视觉成稿](04-视觉成稿/)：视觉初稿、正式设计稿与版本对照。
- [05-校核与迭代](05-校核与迭代/)：数据核对、可读性问题、审稿意见、迭代日志。
- [06-输出与应用展示](06-输出与应用展示/)：印刷/数字交付、展板、适配图与展示效果。

## 推荐设计流程
线框布局→主图表/图符设计→标题与说明文字→辅助图像与视觉统一→数字和单位核验→读者阅读测试→终稿输出。

[设计质量核查表](05-校核与迭代/质量检查清单.md)可作为交付前检查依据。具体画幅、分辨率与文件格式应在选题项目确认后填写，不提前虚构。
