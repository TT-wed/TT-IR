# 设计校核与迭代清单

## 数据与来源
- [ ] 所有展示的数值、类别、时间、位置与基础数据表一致。
- [ ] 单位、口径、来源、年份与必要限制均有说明。
- [ ] 文本/照片/图标的授权、出处、署名需求已核查。
- [ ] 丢失值、异常值、排序规则与归一化方法已记录。

## 信息与叙事
- [ ] 每一版面模块都对应明确的信息单元与读者问题。
- [ ] 重要结论能回溯到字段、计算与原始来源。
- [ ] 标题、注释、图例与图形意义一致，未由相邻关系虚构因果。

## 视觉编码与可读性
- [ ] 点、线、面、体、色彩、位置、符号与统计变量映射明确。
- [ ] 图符重复单位和比例正确；面积/直径/半径未混用。
- [ ] 字体、字号、行距、字距、对比与留白适用于目标媒介。
- [ ] 色彩在黑白或色觉差异情况下仍具备必要的冗余编码。
- [ ] 不重要的装饰没有遮蔽数据或误导比例。

## 交付
- [ ] 源文件可编辑，外部素材可追溯。
- [ ] 文件命名、版本、尺寸、分辨率、出血与色彩模式符合实际要求。
- [ ] 导出文件已人工核验，无文字截断、图像失真或丢失引用。
- [ ] 记录修改意见、确认日期和最终版本位置。
