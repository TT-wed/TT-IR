# 04｜基础数据集构建

## 核心规则：一列一个变量，一个单元格一个原子值
- **列**：一个明确命名且类型一致的变量，如 `地点名称`、`纬度`、`经度`、`年份`、`GDP值`、`图片路径`、`正文文本`。
- **行**：一个明确的观测单位，例如一个地点、一个地区的某一年、一个被调查对象。
- **单元格**：只记录一个原子值；可以是名称（名义）、等级（顺序）、数字（定量）、日期、文字片段或单个图像资源引用（如文件路径/唯一ID）。
- **不要**在一个单元格里写成 `北京，116.4，39.9`、`GDP: 100亿元`、`春夏秋冬` 等多个混杂值。经纬度优先拆为独立数值列，展示时再组合成一个GPS地点信息。
- 一列可以有很多行，**不是每一列只能存一个数据记录**。
- 图像和文本文献以可追溯的资源 ID/路径/文本字段保存；如有多个图片，按记录ID建立独立关联表，不在单格塞多个链接。

## 质量检查
唯一键、数据类型、单位一致、值域、重复记录、缺失、外键、出处、文本/图像权利、记录粒度。不能确定的值用统一缺失标志，而不是零。
