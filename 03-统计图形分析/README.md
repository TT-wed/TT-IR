## 图表条目统一分析框架
每个图表包含：①来源与项目标签、数据字段及可选字段；②基本统计与数据逻辑；③视觉编码；④数据/信息架构；⑤视觉叙事与适用任务；⑥限制及图表替代；⑦可核对源码。

**区分证据类型**：“RAWGraphs 源码事实”仅指已查明的 `metadata.js`、`dimensions.js`、`mapping.js`、`render.js`、`visualOptions.js`、示例配置及更新日志；“设计研究判断”是为了信息图形课程提出的使用建议，非源码作者的原话。
