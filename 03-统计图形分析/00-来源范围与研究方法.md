# 00｜来源范围、版本与研究方法

## 1. 可验证的原始材料
- [官方项目 README](https://github.com/rawgraphs/rawgraphs-charts/blob/cade3b6e1b4d35d365440b1365d51b0dd48c9bce/README.md)：它明确说该仓库是 RAWGraphs App 使用的精选图表集合，依赖 RAWGraphs Core API；提供 sandbox 进行图表开发测试，并提醒图表仍可能发生破坏性变动。
- [package.json](https://github.com/rawgraphs/rawgraphs-charts/blob/cade3b6e1b4d35d365440b1365d51b0dd48c9bce/package.json)：包名 `@rawgraphs/rawgraphs-charts`、版本 `v1.1.0`、Apache-2.0、运行依赖 D3 7 及 d3-sankey、d3-contour、d3-hexbin、d3-voronoi-treemap 等。
- [src/index.js](https://github.com/rawgraphs/rawgraphs-charts/blob/cade3b6e1b4d35d365440b1365d51b0dd48c9bce/src/index.js)：**31 个正式导出图表**，用此文件作为数量的判定依据，而非仅数 `src/` 子文件夹。
- [CHANGELOG.md](https://github.com/rawgraphs/rawgraphs-charts/blob/cade3b6e1b4d35d365440b1365d51b0dd48c9bce/CHANGELOG.md)：v1.1.0 更新图轴共享辅助函数、刻度控制，并改进甘特图和蜂群图选项；v1.0.1 加入弦图并修订多种图形。
- [example/configurations](https://github.com/rawgraphs/rawgraphs-charts/tree/cade3b6e1b4d35d365440b1365d51b0dd48c9bce/example/configurations)：React sandbox 的图表配置和部分数据例子。

## 2. 研究流程
1. 从 `src/index.js` 核对可用图表清单。
2. 对31个图表逐一读取 `metadata.js` 的名称/类别/描述与 `dimensions.js` 的字段、类型约束、必填性及聚合默认值。
3. 交叉检查 `mapping.js` 的聚合与数据重组、`render.js` 的 D3 布局/统计处理、`visualOptions.js` 的交互式参数。
4. 用示例配置辨识纵表、宽表、边表、层级路径表等输入方式。
5. 将源码事实与“信息图形设计课程的适用判断”分别记录，避免把统计学上的最佳实践错误归于作者。

## 3. 输出范围
- 4 个以读者任务为主的检索组、31篇逐图档案及8个横向研究文档。
- **不是**对 RAWGraphs 网页全部图表的网络实时测试，也没有声称运行每个示例或逐项统计验证。
- 不包含原仓库的 SVG 预览图与代码复制件；使用源码永久链接便于核查并减少维护重复。
- 没有源码实现的图表不凭空增加，未将“图表”直接等同于“信息图形的完整作品类型”。

## 4. 版本警示
代码仓库内容会变化，因此本次研究永久链接固定到 `cade3b6e1b4d35d365440b1365d51b0dd48c9bce`。后续升级需重新核对 `src/index.js`、`dimensions.js` 与变更日志，而不是静默套用旧说明。
