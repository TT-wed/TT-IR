# 03｜统计计算、尺度约束与视觉编码核查

## 1. 按数据变量选择视觉通道
|变量|优先视觉通道|源码示例|易误读情况|
|---|---|---|---|
|类别（名义）|位置分组、形状、离散色|bar 的 Bars、矩阵图 X/Y|把类别排序看作真实大小顺序|
|时间/连续自变量|共轴位置|line、stream、Gantt|时间断点被等距连线掩盖|
|数量/频数|长度、高度、明确面积或线宽|bar Size、treemap Size、Sankey value|单位、面积或非线性变换不明|
|构成比例|角度、总面积分割|pie、sunburst|近似角度不利于精确比较|
|层级路径|父子包围、嵌套、树枝|treemap、circlepacking、dendrogram|将关系的“深度”误读为数量|
|多变量|多坐标轴、点位、颜色|parallelcoordinates、bubble|轴顺序与尺度影响整体轮廓|
|网络边权重|边宽、带宽|sankey、alluvial、chord|隐藏的零边/重复边改变叙事|

## 2. 代码层面已确认的特殊计算
- **条形图**：`d3.rollups` 分组，可用字段聚合；未映射 size 则按行数计数。参见 [mapping](https://github.com/rawgraphs/rawgraphs-charts/blob/cade3b6e1b4d35d365440b1365d51b0dd48c9bce/src/barchart/mapping.js)。
- **箱线图**：`q1=quantile(.25)`、`q2=quantile(.5)`、`q3=quantile(.75)`，`IQR=q3-q1`，须线到 `max(min,q1-kIQR)` 与 `min(max,q3+kIQR)`，超出为离群点。参见 [render](https://github.com/rawgraphs/rawgraphs-charts/blob/cade3b6e1b4d35d365440b1365d51b0dd48c9bce/src/boxplot/render.js)。因此不能根据 metadata 中“五数概要”的简写就断言须线始终是最小值与最大值。
- **小提琴图**：分箱计数形成宽度，binsNumber 等选项会影响形状，与常见核密度估计图的统计机制需区别。参见 [render](https://github.com/rawgraphs/rawgraphs-charts/blob/cade3b6e1b4d35d365440b1365d51b0dd48c9bce/src/violinplot/render.js)。
- **Hexbin**：把二维点放进六边形格子，统计每个箱格的点数量；格子直径改变空间密度概貌。参见 [render](https://github.com/rawgraphs/rawgraphs-charts/blob/cade3b6e1b4d35d365440b1365d51b0dd48c9bce/src/hexagonalBinning/render.js)。
- **Alluvial**：连续步骤列构建相邻关联；源代码过滤非正值。参见 [mapping](https://github.com/rawgraphs/rawgraphs-charts/blob/cade3b6e1b4d35d365440b1365d51b0dd48c9bce/src/alluvialdiagram/mapping.js)。
- **Sankey**：`d3-sankey-circular` 的循环连接/布局不能与简单无环过程混为一谈。参见 [render](https://github.com/rawgraphs/rawgraphs-charts/blob/cade3b6e1b4d35d365440b1365d51b0dd48c9bce/src/sankeydiagram/render.js)。
- **Voronoi treemap**：项目元数据明确说面积迭代计算可能不能完全准确代表映射值。参见 [metadata](https://github.com/rawgraphs/rawgraphs-charts/blob/cade3b6e1b4d35d365440b1365d51b0dd48c9bce/src/voronoitreemap/metadata.js)。

## 3. 七项核查清单（设计研究建议）
1. 分母、聚合口径、缺失值和负值是否解释清楚？
2. 轴的零点、时间间隔、类别排序是否支持任务？
3. 面积、半径、角度、线宽、颜色与数值是否一致？
4. 样本量是否足以作分布/密度推断，群组数是否可比？
5. 归一化与多变量刻度是否一致；排名是否能反映实际量差距？
6. 可视化设置是否对结果有影响（分箱数、密度平滑、节点排序、树形布局、色标、标签重叠）？
7. 读者能否看懂并从标签、图例、来源回溯到原始含义？

**这些检查是课程规范，不是 RAWGraphs 自动提供了上述检验。**
