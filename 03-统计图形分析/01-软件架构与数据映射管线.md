# 01｜模块架构、数据映射与渲染管线

## 1. 正式导出边界
`src/index.js` 导出31个图表模块。典型实现：[条形图模块](https://github.com/rawgraphs/rawgraphs-charts/blob/cade3b6e1b4d35d365440b1365d51b0dd48c9bce/src/barchart/barchart.js) 把 `metadata`、`dimensions`、`mapData`、`render`、`visualOptions` 和通用 `styles` 组合成对 RAWGraphs Core 的图表描述对象。

|文件|功能|设计与研究问题|
|---|---|---|
|`metadata.js`|图表名称、ID、原生分类、描述、链接及缩略图|官方意图是什么、与相邻图表如何区分|
|`dimensions.js`|字段映射槽位：名称、类型、必填、多列、聚合|什么数据结构才能生成图表|
|`mapping.js`|从原始数据记录到图形所需对象/关联|是否求和、计数、分组、合并重复边、建立层级|
|`render.js`|D3 计算坐标、几何、布局和绘制|哪些视觉变量实际承担数据编码|
|`visualOptions.js`|画布、颜色、轴、尺寸、排列、标签等参数|如何调节、什么设置可能影响阅读|
|`styles`、`SVG`|通用样式和预览素材|编码样式与预览的边界|

## 2. 源码中常见的四种数据形态
**A 一行一个观测值**：如气泡图 `x/y`、蜂群图 `xValue`、平行坐标图多个数值维度；不应先对每行求和。

**B 按类别聚合后的记录**：条形图 `bars/size/series`，`d3.rollups` 汇总相同类别；条形图未映射 `size` 时以行数作为大小。

**C 多列宽表/平行字段**：分组柱形、堆叠柱形、饼图、雷达图使用多列数值维度（`multiple: true`），不要自动假设能直接传入“类别/数值”长表。

**D 关系与层级路径**：Sankey 使用 `source/target` 边表；Alluvial 使用多个 `steps` 的逐级类别路径；树图使用多列 `hierarchy`。三者数据结构不能互换。

## 3. 实际聚合行为实例
- [Bar mapData](https://github.com/rawgraphs/rawgraphs-charts/blob/cade3b6e1b4d35d365440b1365d51b0dd48c9bce/src/barchart/mapping.js)：按 `series` 和 `bars` 聚合，`size` 未映射时使用记录数。
- [Alluvial mapData](https://github.com/rawgraphs/rawgraphs-charts/blob/cade3b6e1b4d35d365440b1365d51b0dd48c9bce/src/alluvialdiagram/mapping.js)：连续相邻层的类别配对后汇总，不是任意端点流量表；过滤 `value <= 0` 的边。
- [Sankey mapData](https://github.com/rawgraphs/rawgraphs-charts/blob/cade3b6e1b4d35d365440b1365d51b0dd48c9bce/src/sankeydiagram/mapping.js)：构造 `source/target/value` 的流量边，带 `size` 可聚合。
- [Box plot render](https://github.com/rawgraphs/rawgraphs-charts/blob/cade3b6e1b4d35d365440b1365d51b0dd48c9bce/src/boxplot/render.js)：四分位数、IQR 倍数须线、离群点计算在 `render` 内进行。
- [Sunburst render](https://github.com/rawgraphs/rawgraphs-charts/blob/cade3b6e1b4d35d365440b1365d51b0dd48c9bce/src/sunburst/render.js)：把层级路径构建为 `d3.hierarchy` 并通过 `d3.partition` 布局。
- [Violin render](https://github.com/rawgraphs/rawgraphs-charts/blob/cade3b6e1b4d35d365440b1365d51b0dd48c9bce/src/violinplot/render.js)：以 `d3.bin` 分箱再绘制小提琴外形，不能简单宣称此实现使用 KDE。

## 4. 研究实践建议（非官方API规范）
对案例建立一张“原始字段 → 图形槽位 → 运算 → 可视通道 → 读者解释”数据血缘表。这样既可验证大小、颜色、边宽、面积来源，也能避免教学中先模仿画面、后倒推数据。
