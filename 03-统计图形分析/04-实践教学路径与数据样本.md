# 04｜实验沙箱、样本数据与课程实践

## 1. 本项目明确给出的本地运行流程
[README](https://github.com/rawgraphs/rawgraphs-charts/blob/cade3b6e1b4d35d365440b1365d51b0dd48c9bce/README.md)：
```bash
git clone https://github.com/rawgraphs/rawgraphs-charts.git
cd rawgraphs-charts
npm install
npm run sandbox
```
源码使用 Node.js/npm 和 webpack 的 sandbox 示例，`npm run build` 通过 Rollup 构建。这里记录官方说明，**不宣称已在当前环境实际执行构建或验证浏览器截图**。

## 2. 源码自带的教学实验
- [Alluvial 示例](https://github.com/rawgraphs/rawgraphs-charts/blob/cade3b6e1b4d35d365440b1365d51b0dd48c9bce/example/configurations/alluvialdiagram.js)：Titanic.tsv，按 `Class → Survival → Age group → Gender` 的多列路径构建冲积流。
- [Sankey 示例](https://github.com/rawgraphs/rawgraphs-charts/blob/cade3b6e1b4d35d365440b1365d51b0dd48c9bce/example/configurations/sankeydiagram.js)：`sankey-loops.csv` 的 `source/target/value` 边表，展示带循环流的网络。
- [Box plot 示例](https://github.com/rawgraphs/rawgraphs-charts/blob/cade3b6e1b4d35d365440b1365d51b0dd48c9bce/example/configurations/boxplot%20-%20simple.js)：cities.csv，按 `Continent` 分组，对 `Population` 绘制分布概要。
- [Line chart 示例](https://github.com/rawgraphs/rawgraphs-charts/blob/cade3b6e1b4d35d365440b1365d51b0dd48c9bce/example/configurations/linechart%20-%20series.js)：Music.csv，按年份/类型绘制多序列收入趋势。
- [其他配置目录](https://github.com/rawgraphs/rawgraphs-charts/tree/cade3b6e1b4d35d365440b1365d51b0dd48c9bce/example/configurations)：含气泡图、弦图、蜂群图、甘特图、Horizon、饼图、旭日图等示例。注意示例数量与图表数量不是一一对应。

## 3. 课堂练习：从三种数据表看出三种认知结构
|输入示例|字段结构|目标图|分析重点|
|---|---|---|---|
|类别计数表|部门、人数|Bar / Grouped bar|分组、聚合、比较任务|
|逐次观察表|年份、产品、营收|Line / Stream / Bump|趋势、构成、排名差异|
|流量边表|source、target、value|Sankey|有向关系、循环、守恒与单位|
|路径记录表|阶段A、阶段B、阶段C、权重|Alluvial|相邻阶段的组成转移|
|多层分类表|大类、中类、细类、金额|Treemap / Sunburst|父子汇总和面积编码|
|独立测量点|身高、体重、组别|Bubble / Hexbin / Contour|位置、密度、异常与遮挡|

## 4. 建议的课堂作业结构
先绘制无装饰的基本统计图，再明确增添视觉叙事内容所传达的独立信息；每个案例提交一张“字段–计算–图形通道”对应表、一张设计评估表和反例说明。

视觉效果若使用图标、摄影、插画等，与完整信息图形类型的分析应放到02案例库，**不修改该目录**。
