# 05｜源码中的易误判点、局限与更新注意

## 一、源码事实与常见通用介绍并不总相同
1. **Pie chart** 的 `dimensions.js` 必填 `arcs`，要求多个数值列（`multiple:true`），不应默认按长表“类别/值”直接映射。
2. **Box plot** metadata 描述五个统计量，但 `render.js` 采用四分位间距倍数决定须线，且展示离群值；所以“须线=极端样本值”不应成为本实现的教学结论。
3. **Violin plot** 在本版本 `render.js` 使用 `d3.bin` 绘制分箱外轮廓，不应未经源码验证就写成“高斯核密度估计”。
4. **Alluvial** 以多个步骤列自动生成相邻节点间的流动；**Sankey** 映射 source/target 边表，渲染依赖 `d3-sankey-circular` 以支持回环连接。
5. **Voronoi treemap** 的面积拟合是迭代性质，元数据明确承认可能无法完全表达目标数值。
6. **Bar chart** 的 `bars` 允许 `number/string/date`，但本质是分组类别；同样数字字段在直方图意义下需先重新定义数值区间。
7. **Contour Plot / Hexbin / Voronoi** 使用二维数值/日期坐标，不能自动写成“地理地图”；是否属于地理型取决于输入字段是否有真实空间位置意义。
8. **Metadata 分类**有重叠；Voronoi metadata 中的 `Correlations` 首字母大写，检索时应规范化但保留原样可追溯。

## 二、版本与依赖
- `package.json`：RAWGraphs Charts `v1.1.0`，主要 D3 `^7.2.0`。
- `CHANGELOG.md`：v1.1.0 新增共享坐标轴与刻度控制；特别涉及折线、流图、Bump、Horizon、Contour、Hexbin、Voronoi、凸包、气泡、蜂群、甘特、小提琴等。
- README 仍提示图表可能发生不兼容变更。课程档案固定源码提交，不把某次实现结果视为未来版本标准。

## 三、目前没有完成的核验
- 未在独立运行环境逐个运行31图并比对可视输出。
- 未对所有 `render.js` 分支的性能、色彩色弱支持或数值误差进行单元测试。
- 不将仓库代码中的开源组件**自动认定为最佳统计方法**；课件中的可视编码建议需另做用户测试。
- 无官方源数据支持的图表例子仅标注为“教学构造示例”，不冒充 RAWGraphs 自带原始数据。

## 四、下一轮深化的可研究议题
节点流守恒、负权重支持情况、数据缺失处理、样本不均匀、宽表转换、颜色尺度一致性、SVG 导出质量，以及相近图形替换实验。
