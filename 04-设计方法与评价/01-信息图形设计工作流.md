# 从数据到叙事：信息图形工作流

第三讲 P43 给出四步：**A 数据收集与清洗 → B 数据集与结构搭建 → C 视觉编码与版式排布 → D 数据关联与内容呈现**。第一讲 P29 给出数据层→信息层→视觉层→交互层的基本组成。

## 设计实践框架（对原课件的操作性展开）
1. 明确任务、受众、问题与传播场景。
2. 采集原始资料、记录来源和日期；规范单位，排查缺失与偏差。
3. 判断最重要的数据关系属于五种逻辑中的哪种，允许次关系共存。
4. 选择统计图形和数学尺度，做不含装饰的基本草图。
5. 组织信息的总览、局部和证据，规定阅读路径与标题层级。
6. 引入符号、图标、配色、文字、摄影等叙事元素，保持与数据关系一致。
7. 以准确、可读、有效、审美、受众认知负担做迭代评估。
8. 归档原始数据与图例、图片版权、案例与修订记录。

第三讲 P40 强调形式匹配内容、读者知识与专业语境；P44 列出复杂、抽象、缺乏美感、内容过多等初学者问题。

## 不应做的事
先找好看的形式再硬塞数据，或以华丽图标代替数据结构设计。第三讲 P47 和 P70 特别批评这类做法。
