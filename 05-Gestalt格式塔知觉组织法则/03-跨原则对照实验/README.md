# 03-跨原则对照实验

本目录研究 Gestalt 不同分组线索在同一信息图形中如何**协同、竞争或产生误读**。

## 当前实验
- [接近律 × 相似律协同与冲突实验](01-接近律与相似律协同冲突实验.md)：提供四种视觉条件、可实施的任务与评价指标，**当前未实施，没有实验结果**。
- [实验记录CSV模板](02-实验记录模板.csv)：仅列名，无真实受试数据。

## 方法要求
1. 明确真实信息分组和视觉分组是不同概念。
2. 至少提供单一线索、双线索一致、双线索冲突的对照条件。
3. 固定数据对象数量、绘图尺寸、标签、观看环境等混杂因素。
4. 将无正确答案的知觉偏好题，与有明确真实类别答案的信息查找题分开。
5. 记录匿名参与者ID、呈现顺序、反应时间、分组选择、正确率（仅适用于有标准答案的题目）。
6. 解释统计结果时注明样本量、限制和复现条件，不能先假定某条法则始终更强。
