# Gestalt 格式塔知觉组织法则

本目录用于格式塔知觉组织的规则、案例、跨原则实验与设计实践研究。十二条法则属于教学研究框架，并非学界唯一且封闭的清单。

## 按编号排列的子库

1. [01-规则库](01-规则库/README.md)：12条法则的定义、知觉机制、设计分析与风险。
2. [02-案例研究](02-案例研究/案例分析模板.md)：有明确来源的实际案例分析模板。
3. [03-跨原则对照实验](03-跨原则对照实验/README.md)：研究不同分组线索的协同、冲突和误读。
4. [04-设计实践经验](04-设计实践经验/设计实验与经验总结.md)：对照实验及信息设计实践的经验积累。
5. [05-参考文献与修订记录](05-参考文献与修订记录/)：保留空目录，后续按资料补充。

另见 [00-Gestalt概念定义与法则体系](00-Gestalt概念定义与法则体系.md)。

## 研究原则
- 数据关系与视觉分组是不同层次，应分别验证；
- 构造的教学示例不是已经分析的真实案例；
- 未实施的实验只有方案与空白记录，不报告虚构结果；
- 目录编号调整不改变原12条规则的知识内容。
