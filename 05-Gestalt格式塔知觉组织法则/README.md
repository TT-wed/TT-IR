## 分类原则
- Gestalt 并不存在公认的唯一固定条数；这里采用**7个经典分组/线索 + 3个后续扩展线索 + 2个整体组织原则，共12个教学研究条目**。
- 这不是12种统计图，也不是12种信息图形成品类型。
- 用实际视觉证据判断原则，不可仅因出现圆形、线条或颜色就武断认定。
- 与01数据逻辑、02案例类型、03 ISOTYPE 等研究体系保持概念区分。
