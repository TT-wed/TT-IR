# TT-IR｜信息图形知识库

本仓库按数据逻辑、信息图形类型案例、ISOTYPE基础设计方法及统计图形分析四个模块组织。

## 仓库目录
1. [01-信息图形数据逻辑](01-信息图形数据逻辑/README.md)：五种数据逻辑的概念定义与文本案例链接。
2. [02-信息图形类型案例](02-信息图形类型案例/案例库/README.md)：常见信息图形类型、分类案例与词云图型。
3. [03-ISOTYPE-基础图形设计](03-ISOTYPE-基础图形设计/README.md)：ISOTYPE 基础符号设计方法及3份课程案例。
4. [04-统计图形分析](04-统计图形分析/README.md)：RAWGraphs 源码研究和31种统计图形档案。

## 研究与更新原则
- 区分**底层数据关系**、**统计图形**、**视觉编码**、**作品表现类型**及**设计方法**。
- 用用户提供的案例证据判断分类；记录课程页码、可观察依据、未核实内容、方法与局限。
- 同一案例只保存一份主要档案，通过相对链接关联多个类型。ISOTYPE属于基础符号设计方法，并非一类独立的信息图形数据逻辑。
- 01中的A–E概念定义保持纯文本；案例图片只存于02的案例图目录。
- 三份课件对应的79份课堂案例档案中，76份在02案例库，3份ISOTYPE案例迁至03；截至本次调整，图片二进制资产尚未导入GitHub。
