# TT-IR｜信息图形知识库

本仓库聚焦两大主体：**数据逻辑**与**信息图形类型案例**。课程案例与理论分析不断修订，但不在根目录额外划分基础理论、统计图形、设计评价或课程勘误模块。

## 仓库目录
1. [01-信息图形数据逻辑](01-信息图形数据逻辑/README.md)：编年型、层级型、编目型、字母表型、地理图形；保存 A–E 理论定义、案例文本链接，不存案例图片。
2. [02-信息图形类型案例](02-信息图形类型案例/00-案例索引.md)：各信息图形类型的概念定义、案例索引与设计分析。
   - [案例库](02-信息图形类型案例/案例库/README.md)：保存79份课件案例研究档案及扩展分类。
   - [案例图](02-信息图形类型案例/案例图/README.md)：图片资源的统一存储位置。
   - [其他常见信息图型／词云图型](02-信息图形类型案例/其他常见信息图型/词云图型/README.md)：新增的词云图型概念。

## 研究与更新原则
- 区分**底层数据关系**、**统计图形**、**视觉编码**、**作品表现类型**及**设计方法**。
- 用用户提供的案例证据判断分类；记录课程页码、可观察依据、未核实内容、方法与局限。
- 同一案例只保存一份主要档案，通过相对链接关联多个类型。ISOTYPE属于基础符号设计方法，并非一类独立的信息图形数据逻辑。
- 01中的A–E概念定义保持纯文本；案例图片只存于02的案例图目录。
- 三份已整理课件对应的79份课堂案例文本在02案例库中保留；截至本次调整，图片二进制资产尚未导入GitHub。
