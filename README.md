# TT-IR｜信息图形理论、类型与案例知识库

> 三份课程讲义整合版 v0.2｜2026-11-23。课程中的观点保留来源页码；分类判断是可持续修订的研究结论，非原作者逐条明确指出。

## 阅读路线
1. [00-信息图表基础理论](00-信息图表基础理论/README.md)：定义、发展史、DIKW、视觉编码与设计伦理。
2. [01-信息图形数据逻辑](01-信息图形数据逻辑/README.md)：编年型、层级型、编目型、字母表型、地理图形五种**数据架构**。
3. [03-统计图形与图表选择](03-统计图形与图表选择/README.md)：数据类型、六种图表、图表选型及常见误导。
4. [02-信息图形类型案例](02-信息图形类型案例/README.md)：按**信息图形主要表现类型**单点归档课程案例，允许跨类别多标签。
5. [04-设计方法与评价](04-设计方法与评价/README.md)：制作流程、视觉叙事、平衡轮盘、数据/油墨比与 ISOTYPE 基础方法。
6. [05-课程来源与纠错](05-课程来源与纠错/README.md)：三份PDF页码对照、来源、需要继续核实的原文问题。

**分类不是一维的**：数据结构 ≠ 统计图表 ≠ 信息图形表达类型 ≠ 符号设计方法。例如：一个地理数据案例可以用分级设色统计图，并做成混合式专题海报；ISOTYPE 是符号编码方法，不是第六种数据逻辑。

## 资料与案例归档原则
- A–E 理论文档仅放文字、结论与指向02案例的相对链接，绝不存案例图片。
- 02案例采用“主类型唯一归档+辅助标签多重索引”；每个条目记课件名称、PDF页码和待核查项。
- 这批资料整理出79个**课程页面截图档案**（不是79幅已核实作者/来源的独立原创作品）；图像与逐例档案以配套资源包提供，GitHub当前提交为文献、索引及案例元数据。图像需另行上传同名图片路径后才能在GitHub中预览。
- 未有原始数据或作者信息时，不从画面推造数值、计算公式和作品署名；分清“课件原述”和“整理者分析”。
- 原文疑似误标另记[纠错簿](05-课程来源与纠错/待核查内容.md)，不静默改写来源。
