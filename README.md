# TT-IR 信息图形知识库

## 分类原则
01 为**底层数据逻辑**，02 为**成品信息图形表现类型**；两者不是互斥的同一分类体系。

- [01-信息图形数据逻辑](01-信息图形数据逻辑/README.md)：理论定义，仅保留文字和案例相对链接，**不存图片**。
- [02-信息图形类型案例](02-信息图形类型案例/README.md)：类型定义与逐张图像案例。
- [案例分析模板](02-信息图形类型案例/案例分析模板.md)

## 维护规则
1. 用户提供案例图后才建立有证据的具体分析；未提供的图片与案例不得虚构。
2. 每例记录主/辅类型、原始图像出处、数据结构、统计计算、视觉编码、信息架构、叙事架构、误判点。
3. 先据图归纳，再在类型说明中更新方法、原则与反例，并从01理论文档链接到02具体案例文本。
4. 区分事实、推断与一般化设计建议，保留版本记录。
5. ISOTYPE 可作为符号设计方法参与混合信息图形，但并非与这些成品类别同层级的独立类型。
