## 如何区分“原文”与“整理意见”
- **课件原述**：以“第一讲/第二讲/第三讲+PDF页码”给出。
- **图像可观察特征**：只写画面可见的关系、排列、形状和文本。
- **研究者归纳**：信息架构、编码方式、类别判定与设计原则等，是可被后续新案例修订的判断。
- **待核查**：作品署名、历史细节、统计计算、可能误标，统一进入[勘误表](待核查内容.md)。

**图片来源**：从用户提交的三份课程PDF中摘取各案例所在整页截图，以保留课堂注释和来源线索。不是原作品高清档，不建议脱离原课件作为正式出版图像。
