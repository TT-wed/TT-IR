# 如何把已分类的79张案例截图补齐到 GitHub

## 当前状态
- 已通过 GitHub 连接器写入：三讲知识点文档、五种数据逻辑的教材回链、20个分类索引、79份逐例元数据、精选图像分析。
- **尚未直接上传 JPEG**：当前可用的GitHub写入接口可处理文本文件，但本次执行无法把工作容器中的二进制JPEG直接传给该接口。为避免制造失效图片，仓库档案只记录已生成截图的目标路径。
- 本次聊天同时提供 **TT-IR-三讲案例图像与档案.zip**；该ZIP中有79张有文件名和课程页码的JPEG、79份可直接在同级文件夹预览图片的Markdown文档，以及分类索引和CSV/JSON清单。

## 导入到 GitHub 的操作
1. 下载聊天中的配套ZIP，在本地解压。
2. 解压文件夹内，找到 `02-信息图形类型案例`，保留每个分类目录下的 `图片` 子目录和JPEG文件名。
3. 将各类 `图片` 内的JPEG上传到GitHub中同名目录。不要在01数据逻辑目录上传图片。
4. 若同时希望逐案例页面直接显示缩略图，可以将压缩包里的各类 `案例/CASE-xxx.md` 覆盖/更新GitHub现有对应的案例Markdown。压缩包中的这些版本已经内嵌正确的相对图片地址。
5. 核查 `02-信息图形类型案例/00-案例索引.md` 的分类索引及各案例链接。

## 维护约定
- 每张图片对应一个 CASE-xxx 档案。
- 第三讲 P13 左右两个独立案例已裁分为 CASE-043 和 CASE-052。
- 合计79个图像档案，来自78个不同PDF页面；一页可能包含多个作品，因此档案数不代表独立原作数量。
- 文件用于教学研究检索，若公开发布或商业再利用原作品图片，应另核对版权及作品署名。
