# SGCS 风格复用验收清单

## 提取与配置
- [ ] 参考图来源、授权、ID与分析范围已记录。
- [ ] 十三个系统已逐项检查，“不适用”和“未知”明确标记。
- [ ] 每条A/B规则都能追溯到参考图中的证据。
- [ ] 从单张图推导的“稳定基因”已注明置信度限制。
- [ ] 具体主体身份、场景与题材没有误放进不可变风格基因。
- [ ] 原VSCF特定比例数值未被当成普遍标准。

## 四种输出
- [ ] 中文JSON语法正确，13个系统完整。
- [ ] English JSON语法正确，可通过English JSON Schema结构校验。
- [ ] 中文简易提示词从同一风格配置编译，没有新增风格强制值。
- [ ] 自然语言提示词四种模式共用同一核心。
- [ ] 中英文语义、禁止项、软硬约束一致。
- [ ] 所有模板占位符已填写或明确标为未填写。
- [ ] 主题文本、数据、图例及场景要求可用原始资料核验。

## 风格迁移验证
- [ ] 至少测试不同主体、不同题材，而非只复现原图附近变体。
- [ ] 保存每个输出所用模型、版本、提示词、参考图和重要设置。
- [ ] A类硬约束不存在未说明的重大违例。
- [ ] B类软约束变化在有根据的容差内。
- [ ] 风格一致性与主题准确性分别评价。
- [ ] 校验未执行时状态仍为not_tested，没有填写虚构分数。
- [ ] 出现风格/数据冲突时有明确决定及理由。

## 版本发布
- [ ] 风格ID唯一，版本号与变更日志齐全。
- [ ] 旧版配置仍可恢复。
- [ ] 复用说明写明适用的图像模型/媒介/主题测试范围与限制。
