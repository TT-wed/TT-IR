# 05｜一致性校验与复用验证

## 目标
验证两件不同的事情：
1. **风格保真（Style Fidelity）**：不同主题下，生成结果是否保持来自参考集的核心视觉规则？
2. **主题正确（Theme Fidelity）**：新主体与新场景是否准确、可辨认，必要文字和数据是否保持真实？

两者缺一不可。只满足第一项可能生成“漂亮但不符合任务”的图；只满足第二项可能导致风格漂移。

## 五步验证工作流
1. 配置核对：JSON可解析、13系统存在、未填写字段标记清楚，四种输出引用同一Style Core。
2. 锁定检验：A硬约束必须逐项可查，B软约束设置合理容差，C主题槽位不被误锁死。
3. 多主题生成：推荐至少3类明显不同题材；各主题重复生成（具体次数按资源决定），记录模型/版本/参考输入/随机配置。
4. 独立评估：分别检查风格一致性、主体语义、图中文字/统计数据及输出技术规格。
5. 复核修订：写出失败在哪个系统、什么视觉证据支持、如何修改配置、哪个新版本再次通过。

**未开展生成测试时状态必须为 `not_tested`。** JSON结构校验成功不能代替视觉一致性测评；不同图像模型间也不能无验证地认为结果等价。
