# 13个视觉控制系统｜定义与分析操作

每一系统至少填写五项：**观察现象、提取规则、参考证据、分级(A/B/C)、置信度**。13系统是检查范围，不代表每个系统都必须发挥同等强度；没有光影的平面矢量风格可将光线记为“不适用”。

|序号|系统|需要提取什么|观察依据|输出规则|
|---|---|---|---|---|
|01|风格本体 / Style Identity|文化/历史语境、视觉媒介、艺术表达、身份与边界|来源图中可见的形式特征；文化或艺术史出处须外证|风格定义句与禁止混入的风格|
|02|色彩 / Color System|主/辅/强调色、色相、饱和度、明度、面积比例|色板及各色在参考图中的分布位置|色彩规则，色值与比例在可核实前保留空值|
|03|光线 / Lighting System|光源方向、软硬、明暗、环境反射、空间氛围|阴影、投影、反光、光源一致性；平面作品可能不适用|光线描述或不适用条件|
|04|构图 / Composition System|主体位置、平衡、留白、方向与视觉路径|参考图框架和视觉重心的重复关系|空间语法和可变位置边界|
|05|尺度 / Scale System|主体/环境、不同对象之间的比例与层级|相对占画面积、图形大小关系|关系区间，禁止生搬某一风格的比例|
|06|绘画语言 / Rendering Language|描边、笔触、扁平/立体、厚涂/线稿、抽象化|放大查看边线和造型规则|表现技法与负面限制|
|07|边缘控制 / Edge Control|清晰/柔化/丢失边缘、轮廓分级|不同空间层次的线条与焦点分布|主/次/背景边缘规则|
|08|完成度 / Finish Control|主体/背景刻画程度、局部细节和简化|细节密度、笔触与形体概括的实际差异|各区域精度规则；不使用无依据百分比|
|09|信息密度 / Information Density|高/低密度区域、疏密节奏、细节集中位置|分布、重复、留白、局部纹理|复杂度分配与拥挤限制|
|10|材质纹理 / Material Texture|材质的视觉表达、颗粒、粗糙度、表面方向|可见纹理的形态、尺度和一致性|媒介相关纹理规则|
|11|主体设计 / Subject Design|主体轮廓的简化法、动作、尺度、色彩与材质逻辑|多张图中不同对象是否以同一套规则处理|稳定的是塑造方法；实际主体名称归主题适配|
|12|视觉锚点 / Visual Anchor|首要焦点、次要结构、三级提示、对比差|观察阅读顺序、主要对比与空间结构|锚点类型和层级，不固定每张图的实际对象|
|13|视觉张力 / Visual Tension|大小、虚实、动静、色彩、光暗、密度、边界对比|辨认成对关系与在画面中的重复作用|张力组合与可接受范围|

## 每条规则的填写格式
```yaml
系统: ""
规则ID: ""
观察: ""             # 原图中看到了什么
风格规则: ""         # “怎样组织”，不能只列元素名称
支持证据: []         # ref_001、ref_002...
反例或例外: []
置信度: 待定         # 高/中/低
规则分级: 待定       # A硬约束/B软约束/C可变（按实际风格决定）
失真风险: ""
检测方式: ""
```

## 重要区分
- 色彩系统不等于主体颜色名称：主体变更时保留主辅色的**关系与策略**，在需要表达真实品牌/类别含义时，应说明约束冲突。
- 构图、尺度、密度、视觉锚点可能相关，但各自记录对象：构图是组织关系；尺度是相对大小；密度是复杂度空间分配；锚点是注意力等级。
- 绘画语言与材质纹理相关但不相同：媒介/描绘方式 vs 所表现的表面特质。
- 主体设计必须拆成“如何塑造主体”的稳定规则与“主体是谁”的主题变量，否则无法实现跨题材迁移。
- 历史流派、文化含义、心理效应不应仅凭单张图就写成已证实结论。
