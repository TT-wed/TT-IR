# 01｜风格分析标准

## 目标
以参考集为依据，逐项提取13个视觉控制系统，避免仅凭风格标签或单张画面要素推断风格。

## 子文档
- [13系统分析与提取表](01-13系统分析与提取表.md)
- [参考图及证据登记模板](02-参考图集与证据登记.md)

## 分析步骤
1. 收集参考图，标注作者/来源、权属、图像ID、画幅和变体；不推断未核实的来源。
2. 逐图观察色彩、构图、尺度、边缘、密度、材质、主体处理等具体特征。
3. 逐项对比参考集，确定**稳定规律、偶然元素、明显例外、无法判断项**。
4. 每条提取结论记录支持的图像ID、置信度（高/中/低）与风格失真风险。
5. 多维度有冲突时写下优先级，不依赖模型自行决定。

## 质量门槛
没有实图、不足以测量、来源不明、二维图像无法支持的物理解释，一律写“待核查”或 `null`；不能把模板样例填成已提取特征。
