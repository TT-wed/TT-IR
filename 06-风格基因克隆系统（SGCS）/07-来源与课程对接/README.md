# 07｜来源说明、课程关联与研究边界

## 直接来源
1. 用户提供《AI视觉风格克隆体系说明文档（VSCF）》：提出“复制产生图像的视觉生成规则，而不是表面元素”的主张，并列出13种视觉控制系统，提供JSON骨架与6步提取流程。
2. 用户此前明确的SGCS目标：精准提取、结构化JSON、主题扩展/变更、跨题材复用、自适应与四类提示词输出。
3. 《智能辅助设计基础》课程材料（用户另行上传）：四大视觉语言系统、从设计意图至Prompt的转译、风格/材质语法、字体与海报实训、工具群工作流。

此页提供整理**来源说明**而非声称已将原上传文档逐字备份至仓库。

## VSCF与SGCS的关系

|VSCF原始内容|SGCS保留与扩展方式|
|---|---|
|13个视觉控制系统|原样保留13个一级分析对象，并提供可填写字段与证据记录|
|JSON提示词骨架|完整中英JSON模板、字段对照、英文JSON Schema|
|提取不可改变基因|增加A硬约束、B软约束、C可变槽位和冲突解决|
|更换主题/主体/场景|增加主题适配矩阵和四种任务模式|
|按13系统逐项修正|增加跨主题测试、评分、结果留痕及版本追踪|

## 十三系统与原课程四大视觉语言
- 光线语言 → VSCF光线系统。
- 色彩语言 → VSCF色彩系统。
- 构图语言 → 构图、尺度、信息密度、视觉锚点、视觉张力的相关部分。
- 风格材质语言 → 风格本体、绘画语言、材质纹理、边缘、完成度、主体设计的相关部分。

这些映射存在交叉，不应将四系统与十三系统视为互斥的一一对应分类。

## 适用场景与边界
- 适用于系列插画、视觉海报、品牌物料、包装插图和信息图形中的视觉表达统一。
- 不能代替用户已有的信息图形**数据逻辑、统计图形、信息架构与真实数据来源**。
- 对数据图形，必须优先保证统计比例、字段语义、地图坐标、时间先后、图例、文字和单位准确。
- 某些媒介（如无光影的矢量平面风格）不适用VSCF的光比或环境反射参数，应标注不适用。
- 图像生成结果可能受模型、版本、随机采样、参考图机制和输出尺寸影响，跨平台与跨主题“完美复用”不能由JSON结构保证。
- 所有心理效应、文化归属与历史流派判断需要外部资料或案例验证，不能当成由视觉像素直接测量出的结论。

## 课程对接建议
将本模块用于99-XXX主题信息图形设计的“02-主题内容分析（风格标签）”、“06-视觉编码”和“08-设计实施”。与05 Gestalt原则共享实验的对照设计思路，但不能把风格相似度实验等同于Gestalt分组心理学实验。
