# 风格基因克隆系统｜系统定位与术语

## 目的
将给定参考图像的视觉特征转化为**有证据、可解释、可迁移、可复用**的规则集合，从而支持主体变更、主题扩展、场景替换与不同传播媒介。目标是高保真风格一致性，而非逐像素复制参考图。

## 五个必须区分的对象
1. **参考特征（Observed Feature）**：在某一张图上实际观察到的颜色、形态、光线、排布。
2. **风格基因（Style Invariant）**：在参考集反复出现且对风格识别重要的视觉规律；需记录证据和边界。
3. **主题内容（Theme Content）**：题材、人物、物品、场景、文本等可变化的信息。
4. **生成指令（Compiled Prompt）**：把稳定规则和主题内容结合后传递给具体图像模型的文字/数据。
5. **复用结果（Validation Result）**：使用不同主题实际生成后，通过明确评价过程得到的证据；没有测试即不得标注“通过”。

## 生成公式
```text
Prompt = Style Core + Theme Adapter + Output Specification + Negative Constraints
```
必要时增加平台专属实现层（如参考图、权重或种子），但平台参数不可混入通用 Style Core。

## “精准”的操作定义
- **提取准确**：每项描述能回到参考图位置与观察证据，不凭推测断言艺术史来源。
- **风格稳定**：换主体/主题/场景后，关键视觉关系在预定容差范围内保留。
- **主题有效**：新增主体可辨认、符合任务，不因锁风格破坏场景逻辑。
- **可复现**：记录模型版本、提示词版本、参考图、输出规格与必要随机设置。
- **多平台适用**：只保证语义逻辑可翻译；每个平台需要适配及重新验证，不能承诺像素级复现。

## 使用路径
至少1张参考图即可建立**待验证**草案，建议3—9张可证明属于同一风格的参考图，区分共同特征与偶然特征；不得把用户未提供的资料当作真实参考。

## 原始13系统与SGCS的关系
保留原始VSCF十三项：风格本体、色彩、光线、构图、尺度、绘画语言、边缘控制、完成度、信息密度、材质纹理、主体设计、视觉锚点、张力。它们既不是13种作品类型，也不是13个相互独立的统计量。分类和参数来自用户提供的《AI视觉风格克隆体系说明文档（VSCF）》，SGCS新增提取证据、分级规则、自适应层和验证方案。

**重要限定**：原VSCF文档中的“巨大环境+微小主体”、主体2%—8%与分区完成度百分比，是**某类风格的示例参数**，不适用于所有风格。每项规则都必须从真实参考集重新判断。
