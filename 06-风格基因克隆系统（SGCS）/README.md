# 06｜风格基因克隆系统 SGCS v1.0

**Style Genome Cloning System** — 将参考图中的视觉生成规律转写为可迁移的风格配置与提示词。

> 版本：1.0（设计规范与模板）；当前未针对具体参考图进行提取，也未完成真实跨主题一致性测试。**“完美复用”属于目标，不是已经实现或能够无条件保证的结果。**

## 不变与可变的分离
```text
已核查的参考图集
   ↓ 观察 → 证据 → 13维度
Style Core（固定基因：按风格判定）
   + Theme Adapter（主题／主体／场景／媒介）
   + Output Constraints（尺寸、文字、格式）
   + Negative Constraints（破坏风格的行为）
   ↓ 一次编译，四种输出
中文JSON｜English JSON｜中文简易提示词｜自然语言提示词
   ↓ 跨主题测试与修订
可追溯的风格版本
```

## 交付契约
- **交付格式四类**：①中文 JSON、②English JSON、③中文简易提示词、④自然语言提示词。
- **自然语言提示词内有四个任务模式**：原风格复现、主体迁移、系列扩展、跨题材变更。四个模式共用同一份 Style Core，不各自发明风格。
- **13系统全部覆盖**：原 VSCF 的主体设计系统被拆为“稳定的主体塑造方法”与“可替换的实际主体”，避免把主体身份错误锁死。
- JSON只是结构化语义，不意味着图像模型会严格执行或在不同平台、版本、随机种子上生成完全相同的结果。
- 未获得参考图片时，输出模板应显示未填写项，不编造颜色、比例、文化来源或媒介属性。
