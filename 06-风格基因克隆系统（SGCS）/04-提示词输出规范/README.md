# 04｜提示词输出契约

根据**一份 Style Core + 本次 Theme Adapter**，生成以下四种正式交付件：

|编号|格式|用途|文件|
|---|---|---|---|
|1|中文 JSON|中文阅读、修订及风格档案|[模板](../03-JSON配置规范/风格配置模板.zh.json)|
|2|English JSON|跨平台交换及机器读取|[模板](../03-JSON配置规范/style-profile.template.en.json)|
|3|中文简易提示词|快速复制到图像工具|[简易模板](中文简易提示词.md)|
|4|自然语言提示词|按任务生成完整叙述|[四个任务版本](自然语言提示词四种复用版本.md)|

## 自然语言内部的四个任务版本
1. 精准复现；2. 主体迁移；3. 系列扩展；4. 主题变更与自适应。它们不是四个彼此独立的风格，而是**同一个Style Core**在不同任务情境中的编译结果。

## 输入条件
至少提供：参考图、明确的风格定义、关键硬约束、本次主题、主体、场景、交付媒介及禁忌项。真实信息图需补充准确数据、文字和单位。

## 编译约束
- **禁止随意写入未在Style Core出现的颜色、光线、材质、构图强制参数。**
- 检查所有 `{{变量}}` 是否填值；缺值则标记待填写，不擅自编造。
- 保留风格关系而不是机械复制原图所有对象；存在任务冲突时执行02中的决策优先级。
- 负面提示词明确指定“禁止什么”及其破坏的规则，不用“好看、高清、大师级”代替可检验特征。
- 输出后按05进行核对；平台转换时专属参数独立记载。

## 可复用性边界
描述越详细不保证越“完美”；模型自身能力、语义理解、参考图机制和采样随机性会影响执行。可复用性的证据来自系列生成与人工/客观双重评估。
