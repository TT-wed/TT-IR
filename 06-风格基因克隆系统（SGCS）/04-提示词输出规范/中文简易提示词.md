# 中文简易提示词｜通用复用模板

> 使用条件：先把下方的“风格规则摘要”从已经完成的中文/English JSON 中提取出来；未提取时不可用空泛的“原风格完全不变”替代具体规则。

## 可复制模板

```text
任务：以【风格名称】为统一视觉风格，创作【当前主题】的信息图形/插画/海报（载体：【应用载体】）。
主体：【当前主体】；场景：【当前场景】；受众：【目标受众】；目标：【叙事意图】。

固定风格基因（以下必须与风格JSON逐项一致）：
风格本体：【风格定义句】；
色彩：【主色/辅色/强调色及比例】；
光线：【光源/光质/明暗规则，若不适用请写“无光影建模”】；
构图和尺度：【主体位置/视觉路径/留白/相对比例】；
造型及边缘：【扁平或立体方式/线条/笔触/边缘层级】；
完成度与疏密：【细节集中位置/背景处理】；
材质与主体塑造：【质感规则/新主体如何融入同一风格】；
视觉锚点与张力：【主次焦点/对比关系】。

只允许主题、主体、场景、必要文字及内容细节按照主题接口改变；其他变化须落在软约束允许的范围内。
负面限制：【禁止的色彩/材质/图形表现/构图冲突】。
交付：【画幅比例】、【文字策略】、【输出规格】。

不要直接复制参考作品中与新主题无关的对象；优先保证数据、文字、符号意义和题材准确。若新内容与风格硬约束冲突，标注具体冲突并按约束规则处理。
```

## 压缩调用版（填好上面的风格摘要后使用）

```text
以【风格定义句】的视觉语法创作【主题】（主体：【主体】，场景：【场景】）。严格遵循已提取的【色彩比例】【光线逻辑】【构图及尺度】【绘画方式】【边缘】【完成度】【疏密】【材质】【主体塑造】【视觉锚点】【张力】；只替换主题内容，不替换风格规律。输出【媒介/比例/文字】，避免【禁止项】。主题信息必须准确、可辨。
```

> **提醒**：压缩版只有在实际填写具体风格规则、并且目标工具能获取风格配置或参考图的情况下才有足够信息。单独发送仅含“保持原风格”而没有原图/风格定义的提示词，不具备可靠复用性。
