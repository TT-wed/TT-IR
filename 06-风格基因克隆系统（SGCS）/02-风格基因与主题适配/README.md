# 02｜风格基因与主题适配

## 核心目标
把风格规则与具体题材解耦：**主题可以替换，视觉组织机制尽量保持稳定**。

- [约束分级与冲突决策](01-基因分级与冲突处理.md)
- [主题适配矩阵](02-主题自适应矩阵.md)

## 分层
- **A 硬约束（Style Lock）**：改变后明显破坏核心风格身份的规则，必须保持；数量与内容由真实参考集决定。
- **B 软约束（Style Preference）**：可在明确容差内调整，如主体大小的轻微变化。
- **C 内容槽位（Theme Adapter）**：主题、主体、场景、文本内容及任务信息可变，但要遵循A和B定义的塑造方式。
- **禁止项**：不是简单负面词，而是有因果说明的风格冲突，例如“加入写实摄影肤质会破坏扁平剪影表现”。

不要先验地把13维中的所有字段都硬锁。若主体相关的实际类别、结构、安全标注或数据编码必须变化，应以主题正确性优先，必要时声明该迁移无法完全保留特定风格规则。
