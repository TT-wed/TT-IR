# 其他常见信息图型

该目录用于收录不属于当前00—15主分类、但在信息图形设计中经常使用的表达形式。

## 子类别
- [词云图型](词云图型/README.md)：用词语的视觉权重和空间排列呈现文本内容及词项分布。

## 分类规范
1. 这里是**表现形式分类**，不替代01目录的编年、层级、编目、字母表、地理等基础数据逻辑。
2. 新增子类别时建立各自的 `README.md`，说明定义、适用数据、统计方法、视觉编码、信息架构、叙事方式及局限。
3. 实际作品的逐例分析仍存于 [案例库](../案例库/README.md)，图像资源存于 [案例图](../案例图/README.md)，不要将相同图像复制在多个类别。
4. 未提供的案例不虚构，不把词云中装饰性字体变化误当作真实频数。
