# 词云图型（Word Cloud）

> 分类：其他常见信息图型 → 词云图型。当前为概念框架，尚无本仓库已核实的词云案例图。

## A. 基本数据逻辑
对文本材料进行分词、归一化和词项统计，形成 `词项 → 权重` 结构，常见权重是词频，也可以是经过定义的 TF-IDF、重要度评分等；必须说明统计口径。词项可有主题分组，但**词云的空间位置通常不代表词语间的精确距离或因果关系**。

## B. 统计方法与计算
- 预处理：中文分词、停用词处理、别名归一、词形归并、重复内容处理。
- 统计：词频计数、相对词频、关键词权重、TF-IDF（在合适文本集合中）。
- 若按文本分组或时间变化对比，应保持算法、词表过滤、字体尺度范围等参数一致。
- 词云不适合精确数值比较；需要排名或精确数量时配合排序条形图和数据表。

## C. 视觉编码
- **字号/字面积**：可表达词项权重，但面积与字号不是线性等价；必须交代大小映射规则。
- **色彩**：可编码类别、情感倾向或强调层级。若纯装饰，应避免使人误以为对应额外数据。
- **布局、方向、密度**：主要用于空间排布和可读性，非定量位置编码；慎用过度旋转和不规则形状裁切。
- **字形**：重视中文识读、文字对比度、无障碍及小字号词语的可辨认性。

## D. 数据／信息架构
文本范围及来源 → 清洗与分词 → 词频/权重表 → 排序筛选 → 视觉映射与排布 → 释义、注释及数据说明。

建议保留数据字典：原文来源、采样时期、语料规模、分词规则、停用词表、权重算法和显示阈值。

## E. 视觉叙事架构
主题导入 → 关键高频/高权重词显现 → 相关词簇与具体语境解释 → 结论和限制说明。对于比较任务，可并列多个词云并补充数值图表。

## 判定边界
- **词云图型**：词语本身作为视觉符号，大小/颜色等与文字数据或主题表达有关。
- **文字型/列表型信息图形**：文字以列表、段落、编号为主要阅读结构，不一定依据词项权重。
- **词云 vs. 字母表型**：词云并不以 A–Z、拼音或索引顺序为核心排序逻辑。
- **词云 vs. 文字装饰**：若字号完全出于审美选择而与数据无关，应标记为文字图形/字体设计，而不是统计词云。
