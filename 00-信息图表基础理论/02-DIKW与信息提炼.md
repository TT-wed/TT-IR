# DIKW：从数据到智慧

第二讲 P4–6 以 Data → Information → Knowledge → Wisdom 描述从原始记录到有上下文的信息、规律理解、行动决策的路径。课件以天气为例（P5）：
- 数据：温度23℃、湿度65%、气压1013 hPa；
- 信息：今天多云、体感舒适；
- 知识：结合季节天气模式理解环境；
- 智慧：为郊游和着装做决定。

## 设计对应
数据清洗和规范 → 组织和比较 → 发现关系与模式 → 标注结论及决策条件。

第二讲 P7–9 强调：展示与隐藏同样重要、功能限制形式、减少读者在“查找—记忆—排序—比较”上的认知负担。第二讲 P12–13 用地图版与预排序条形图版对照，表明**预排序可以降低读者完成定量比较的工作量**。

## 应用原则
- 隐藏次要信息不等于隐瞒会改变结论的数据，应保留来源与可追溯路径。
- 信息提炼应该筛选问题与阅读次序，而不是随意删掉不便于设计的数据。
- 结论只在证据允许的范围内表达，避免从相关性直接推因果。
