# 数据诚信、信息取舍与受众

第一讲 P2、P30、P36、P37 和第二讲 P2、P7–8 均强调准确、透明、功能与受众理解。第一讲 P30 将数据质量概括为权威性、准确性、时效性、完整性。

## 四项检查
1. **事实基础**：说明数据出处、范围、统计口径和处理方式，不擅自修改数值。
2. **视觉诚实**：反对截断基准造成的柱长夸大、面积/半径混用、虚假色阶、忽略关键数据。
3. **语境完整**：标题、排序、强调和筛选不能掩盖影响结论的背景。
4. **受众适配**：按媒介、读者知识、可访问性与任务深度决定形式（第一讲 P37）。

第一讲 P36 提到 Tufte 的 Lie Factor（图形变化幅度与数据变化幅度之比），用于讨论可视化欺骗。第三讲 P56 用“图表垃圾”批判妨碍理解的表面修饰。
