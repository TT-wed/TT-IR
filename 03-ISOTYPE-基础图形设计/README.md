# 03-ISOTYPE-基础图形设计

本目录专门研究 ISOTYPE 的历史与文献、图符语言、视觉编码及设计实践。

ISOTYPE 是一种**基础图形设计和信息表达方法**，不是一类与其他成品信息图形平行的信息图形类型。

## 目录导航
- [01-历史与文献](01-历史与文献/)：预留历史资料与文献研究目录。
- [02-图符语言与视觉编码](02-图符语言与视觉编码/)：预留图符体系、编码规范研究目录。
- [03-案例研究](03-案例研究/)：仅按既定目录结构预留文件夹，**目前不存放案例**。
- [04-设计实践](04-设计实践/)：预留设计实验、方法总结与规范目录。
- [00-ISOTYPE概念与方法](00-ISOTYPE概念与方法.md)：概念、基础方法、数据关系及设计原则。
